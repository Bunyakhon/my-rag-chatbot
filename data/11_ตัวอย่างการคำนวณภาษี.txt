=== ตัวอย่างการคำนวณภาษีเงินได้บุคคลธรรมดา ===

ตัวอย่างที่ 1: มนุษย์เงินเดือน (เงินได้ประเภทที่ 1 เพียงอย่างเดียว)
เงื่อนไข: นายสมชาย (โสด) เป็นพนักงานบริษัท มีเงินเดือนเดือนละ 50,000 บาท (รวมทั้งปี 600,000 บาท) จ่ายประกันสังคม 9,000 บาท จ่ายเบี้ยประกันชีวิต 20,000 บาท ถูกหักภาษี ณ ที่จ่ายไว้ทั้งปี 15,000 บาท

ขั้นตอนการคำนวณ:
1. เงินได้พึงประเมิน 40(1) = 600,000 บาท
2. หักค่าใช้จ่าย (50% แต่ไม่เกิน 100,000 บาท) = 100,000 บาท
   -> คงเหลือเงินได้หลังหักค่าใช้จ่าย = 500,000 บาท
3. หักค่าลดหย่อน:
   - ลดหย่อนส่วนตัว = 60,000 บาท
   - ประกันสังคม = 9,000 บาท
   - ประกันชีวิต = 20,000 บาท
   -> รวมค่าลดหย่อน = 89,000 บาท
4. เงินได้สุทธิ = 500,000 - 89,000 = 411,000 บาท

5. คำนวณภาษีตามอัตราก้าวหน้า:
   - ขั้น 0 - 150,000 บาทแรก (0%) = 0 บาท
   - ขั้น 150,001 - 300,000 บาท (150,000 x 5%) = 7,500 บาท
   - ขั้น 300,001 - 411,000 บาท (111,000 x 10%) = 11,100 บาท
   -> รวมภาษีที่คำนวณได้ = 0 + 7,500 + 11,100 = 18,600 บาท

6. หักภาษี ณ ที่จ่ายที่ชำระไว้แล้ว:
   - ภาษีที่ต้องชำระสุทธิ = 18,600 - 15,000 = 3,600 บาท
สรุป: นายสมชายต้องชำระภาษีเพิ่มเติมจำนวน 3,600 บาท

-----------------------------------------------------------------------

ตัวอย่างที่ 2: แม่ค้าขายของออนไลน์ (เงินได้ประเภทที่ 8)
เงื่อนไข: นางสาวมะลิ (โสด) ขายของออนไลน์ตลอดปีมีรายได้รวม 1,200,000 บาท เลือกหักค่าใช้จ่ายแบบเหมา 60% มีค่าลดหย่อนส่วนตัว 60,000 บาท และประกันชีวิต 10,000 บาท ถูกหัก ณ ที่จ่ายไว้ 0 บาท

วิธีที่ 1: คำนวณจากเงินได้สุทธิ
1. เงินได้พึงประเมิน 40(8) = 1,200,000 บาท
2. หักค่าใช้จ่ายเหมา 60% = 720,000 บาท
   -> คงเหลือเงินได้หลังหักค่าใช้จ่าย = 480,000 บาท
3. หักค่าลดหย่อน (ส่วนตัว 60,000 + ประกัน 10,000) = 70,000 บาท
4. เงินได้สุทธิ = 480,000 - 70,000 = 410,000 บาท
5. คำนวณภาษีตามอัตราก้าวหน้า:
   - 0 - 150,000 บาท (0%) = 0 บาท
   - 150,001 - 300,000 บาท (5%) = 7,500 บาท
   - 300,001 - 410,000 บาท (110,000 x 10%) = 11,000 บาท
   -> รวมภาษีตามวิธีที่ 1 = 18,500 บาท

วิธีที่ 2: คำนวณแบบเหมา 0.5% (เนื่องจากมีเงินได้ประเภทที่ 8 เกิน 120,000 บาท)
- ภาษีวิธีที่ 2 = 1,200,000 x 0.005 = 6,000 บาท

สรุปการเปรียบเทียบ:
ภาษีวิธีที่ 1 (18,500 บาท) สูงกว่าวิธีที่ 2 (6,000 บาท) ดังนั้น นางสาวมะลิ ต้องชำระภาษีตามวิธีที่ 1 เป็นจำนวนเงิน 18,500 บาท
